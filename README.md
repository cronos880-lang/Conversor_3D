Descomprime el ZIP completo en una carpeta nueva y abre `Iniciar_R17.bat`, con Python 3.12 de 64 bits como R7/R16. El encabezado debe indicar R17 experimental.

Esta revisión reconstruye cuerpos de revolución desde perfiles medidos y conserva los rebajes originales. En Body sustituye 11.667 caras planas por 426 caras, con cinco cilindros, tres conos y los nueve rebajes inferiores comprobados. Los perfiles de precisión y la interfaz se mantienen.

La guía ranurada conserva la conversión R16 de 248 caras; sus propuestas más compactas fueron rechazadas. El informe detalla los resultados reales, los modelos independientes, la regresión y las pruebas pendientes de Windows nativo y Onshape.
