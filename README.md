Descomprime el ZIP completo en una carpeta nueva y abre `Iniciar_R18.bat`. Requiere Python 3.12 de 64 bits y el entorno CAD del Visor, como R7/R17. El encabezado debe indicar R18 experimental.

Flame pasa de 1.099 planos a 422 caras y Base de 13.609 planos a 463 caras, con cilindros reales y sus detalles conservados. Body conserva el DATA del STEP aportado por el usuario. Los perfiles geométricos y la interfaz se mantienen.

El informe incluye mediciones, comparaciones de aristas STEP, controles independientes, regresión y las comprobaciones pendientes de Windows nativo, Onshape e impresión física K1C. La familia es acotada; la guía sigue facetada y la bancada se conserva como regresión.
