# perfeccion_Visualizador: fase cubo-carrito

El cubo-carrito y sus tres giros probados convierten en STEP válido y pasan
reimportación, autointerferencias y medición geométrica densa, con los límites
originales. Las 12 piezas que convertían siguen pasando con indicadores idénticos.
35 pruebas automáticas aprobadas, sin omisiones.

- [Descargar el STEP del cubo-carrito](cubo-carrito.step?raw=true)
- [Informe de resultados y pruebas pendientes](INFORME_RESULTADOS.md)
- [Parche de esta fase](CAMBIOS_FASE_CUBO.patch)
- [Archivos modificados](ARCHIVOS_CAMBIADOS.md)
- [Huella y tamaño del paquete](paquete.json)

Extraer el ZIP en una carpeta nueva. Incluye la aplicación completa, fuentes,
STL de prueba, STEP, registros, métricas y manifiesto SHA-256. No sobrescribir
la instalación estable. La carpeta de aplicación es `Visor_experimental_fuentes`.

Entrega experimental del Visor Python aportado: no actualiza ni valida el motor
WebAssembly de GitHub Pages. El embudo se ha aplazado; el conector no se ha
repetido. Windows nativo y Move face en Onshape siguen pendientes. Por ello no
se declara una versión de uso global con las 14 piezas aprobadas.
