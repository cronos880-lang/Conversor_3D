# Instrucciones del proyecto

- Mantener la interfaz HTML en español y un lanzamiento simple.
- Probar los cambios de conversión con `python -m pytest -q` en el entorno instalado; comprobar el navegador cuando cambie la interfaz.
- No presentar un STEP facetado como reconstrucción paramétrica ni prometer perfección para STL arbitrarios.
- El usuario autoriza guardar los cambios terminados y probados en GitHub sin confirmación adicional. No forzar pushes ni sobrescribir cambios ajenos.
- Utilizar el checkout existente; no crear worktrees salvo petición explícita.
